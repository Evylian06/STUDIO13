STUDIO 13 — CONFIGURACIÓN (Supabase + Cloudinary)
=================================================

ARQUITECTURA
------------
- Supabase: login del admin, textos, categorías, orden, publicado/no publicado
- Cloudinary: almacén de imágenes (optimización automática en la web)
- Web pública: lee datos de Supabase y muestra URLs de Cloudinary

PARTE 1 — SUPABASE
------------------
1. Crear proyecto en https://supabase.com
2. SQL Editor → ejecutar supabase/schema.sql
3. Authentication → Users → Add user (email + contraseña del admin)
4. Settings → API → copiar en js/supabase-config.js:
   - Project URL → SUPABASE_URL
   - anon public → SUPABASE_ANON_KEY

PARTE 2 — CLOUDINARY
--------------------
1. Crear cuenta en https://cloudinary.com
2. Dashboard → copiar Cloud name → js/cloudinary-config.js → CLOUDINARY_CLOUD_NAME
3. Settings → Upload → Upload presets → Add upload preset:
   - Name: studio13_unsigned (o el que prefieras)
   - Signing Mode: Unsigned
   - Folder: opcional (el código usa studio13/{seccion})
4. Copiar el nombre del preset → CLOUDINARY_UPLOAD_PRESET

PARTE 3 — BORRAR IMÁGENES (opcional pero recomendado)
----------------------------------------------------
Para que «Eliminar» borre también el archivo en Cloudinary:

1. Instalar Supabase CLI y enlazar tu proyecto
2. En Supabase → Project Settings → Edge Functions → Secrets, agregar:
   - CLOUDINARY_CLOUD_NAME
   - CLOUDINARY_API_KEY
   - CLOUDINARY_API_SECRET  (Dashboard → API Keys — no la subas al sitio público)
3. Desplegar la función:
   supabase functions deploy delete-cloudinary-image

Sin esta función, al eliminar se quita de la web pero el archivo puede quedar en Cloudinary.

PARTE 4 — PUBLICAR EL SITIO
---------------------------
- Usa Netlify, Vercel o similar con HTTPS
- Panel admin: https://tudominio.com/admin/
- Sube también la carpeta con tus imágenes locales de respaldo (logo, etc.)

ARCHIVOS DE CONFIGURACIÓN
-------------------------
js/supabase-config.js     ← URL y anon key de Supabase
js/cloudinary-config.js   ← cloud name y upload preset

Usa los archivos .example.js como plantilla.

NOTAS
-----
- Sube JPG o WebP optimizados (no RAW/TIFF en la web).
- storage_path en la base de datos guarda el public_id de Cloudinary.
- Si falta configuración, la web muestra el HTML estático de respaldo.
- Categorías del sitio: js/categories.js (deben coincidir con el panel admin).
- No subas js/supabase-config.js ni js/cloudinary-config.js al repositorio público;
  usa los archivos .example.js y configura en el servidor de despliegue.
